# Moments Gallery

Professional responsive image gallery for an internship task.

## Features
- HTML5 structure
- Professional responsive CSS layout
- JavaScript category filters
- Hover effects and smooth transitions
- Lightbox/full-screen image viewer
- Previous and Next buttons
- Keyboard navigation: Left, Right and Escape
- Mobile/tablet/desktop responsive design

## Required image files
Keep these files in the same folder as `index.html`:

`nature1.jpg`
`nature2.jpg`
`animal11.jpg`
`animal12.jpg`
`travel11.jpg`
`travel12.jpg`
`architecture1.jpg`
`architecture2.jpg`

## Run in VS Code
Open the folder in VS Code and use Live Server to open `index.html`.

## GitHub Pages
After uploading the complete folder to GitHub:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
